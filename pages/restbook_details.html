RestBook API

Vue d'ensemble

RestBook est une API RESTful développée en PHP pour la gestion d'une bibliothèque numérique. Ce projet, réalisé en deuxième année de BTS SIO, met en œuvre les principes REST pour permettre la gestion complète des ressources livres via des endpoints HTTP.

Détails Techniques

  • Architecture REST complète
  • Utilisation de l'ORM eloquent avec CodeIgniter
  • Gestion des requêtes et réponses HTTP
  • Endpoints pour la gestion des livres, auteurs et utilisateurs
  • Authentification JWT
  • Gestion des erreurs HTTP standardisée
